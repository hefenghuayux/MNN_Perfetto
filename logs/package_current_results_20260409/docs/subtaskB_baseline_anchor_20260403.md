## 当前结论

- 以当前基线脚本口径看，Prefill 峰值仍在 `6` 线程附近。
- Decode 最优点明确落在 `5` 线程附近。
- `4` 线程时手动绑核收益非常明显，Prefill 和 Decode 都显著高于默认调度。
- `5` 线程时默认调度和手动绑核几乎等价，说明这一区间系统调度已经较稳定。
- `6` 线程时手动绑核对 Prefill 略有帮助，但 Decode 反而略低于默认调度。
- 因此后续论文若先写 baseline 结果，可以把 `Prefill 参考 6 线程、Decode 参考 5 线程` 继续作为主线口径。
