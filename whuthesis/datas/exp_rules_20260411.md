# 第4章统一实验口径（work_steal 版本）

## 固定前提

- 当前正式优化版以 `prefill=work_steal`、`decode=dynamic` 为准。
- 主实验输入固定为 `prefill=512 token`、`decode=128 token`。
- 统一采用 `1` 次 warmup + `5` 次正式测量。
- 结果统一报告 `mean ± std`。

## 固定运行参数

- `-a cpu`
- `-kv true`
- `--split-phase-bench`
- `-rep 5`
- 不显式传 `-mmp`，当前口径视为 `mmap=false`
- `--decode-dynamic-blocks` 默认不显式传参，保持程序默认口径

## 默认记录指标

- `pp512`：Prefill 时间或吞吐
- `tg128`：Decode 总时间或吞吐
- `decode tok/s`
- `E2E`
- `TTFT`

说明：
- 现有 2026-04-09 的已完成结果主要覆盖 `pp512 / tg128 / decode tok/s / E2E`。
- `TTFT` 仍是第4章保留指标，但若当前程序未直接打印，需要在后续实验阶段统一补采或补提取。

## 环境控制

- 开始正式测量前保持手机空闲。
- 温度明显漂移时暂停，尽量回到冻结时的温度区间再继续。
- 同一小节内的多组实验尽量连续完成，减少环境波动。

## 输出目录与命名

统一输出到：

- `/home/hefeng/MNN_last/MNN_Perfetto_hybrid_stepwise/whuthesis/datas`

默认命名：

- 表格：`tab_<topic>_YYYYMMDD.tex`
- 曲线数据：`fig_<topic>_YYYYMMDD.tsv`
- 说明：`notes_<topic>_YYYYMMDD.md`

每个结果文件都应明确：
